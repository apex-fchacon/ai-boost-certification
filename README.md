# AI Boost Certification — Everforth Apex
## Assessment Platform · v2.0

A 5-stage knowledge assessment for the AI Boost Automation QA system,
with **per-student localStorage progress tracking** and **Tailwind CSS CLI** compilation.

---

## Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Build Tailwind CSS (required before opening in a browser)
```bash
npm run build
```

### 3. Open the app
```bash
# Option A — open directly (localStorage works in Chrome/Firefox/Edge)
open index.html

# Option B — serve locally (recommended for consistent behavior)
npx serve .
# then open http://localhost:3000
```

---

## Development

```bash
# Watch mode — auto-rebuilds CSS on file changes
npm run watch

# Then edit index.html or src/input.css and the CSS updates live
```

## Student Progress — localStorage

Progress is **automatically saved to localStorage** after every confirmed answer.

| Feature | Detail |
|---|---|
| Storage key | `aiboost_cert_v2` (browser localStorage) |
| Per-student isolation | Each student identified by name |
| Auto-save trigger | After each question is confirmed |
| Resume | Click **▶ Resume Session** on the landing page |
| Clear all | Click **🗑 Clear All** on the saved sessions panel |
| Delete one student | Click **🗑** on any session card |

### What is saved per student
- Current stage and question index
- All previous answers in the current stage
- Stage scores for completed stages
- The **exact random question set** used (so resume continues with same questions)
- Certificate ID (once generated)

## Tailwind CSS CLI Usage

This project uses the **Tailwind CSS CLI** (v3) — no CDN, no browser-side compilation.

```bash
# One-time build
npx tailwindcss -i ./src/input.css -o ./dist/output.css --minify

# Development watch mode
npx tailwindcss -i ./src/input.css -o ./dist/output.css --watch
```

Custom theme extensions in `tailwind.config.js`:
```js
colors: {
  ef: {
    dark:   '#1B3A35',   // Everforth dark green
    lime:   '#C8FF00',   // Everforth lime
    teal:   '#37B3A2',   // accent
    amber:  '#EE9F2D',   // warm accent
  }
}
```

## Scoring

| Threshold | Value |
|---|---|
| Questions per stage | 10 (randomly selected from a pool of 15) |
| Total questions | 50 |
| **Pass threshold** | **95% → 48 / 50 correct** |
| Certificate issued | Yes — with unique verifiable ID (`EF-XXXXX-YYYYY`) |
